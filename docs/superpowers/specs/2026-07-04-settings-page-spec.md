# Petsona 设置页面 SPEC

日期：2026-07-04

范围：`petsona-main` 设置页。本文只定义设置页第一版需求，不包含实现计划。

## Problem Statement

`petsona-main` 目前设置页仍是占位状态，但桌宠已经存在多个可调能力：桌宠显示/隐藏、动作频率、主动闲聊频率、宠物人设描述、大模型接口配置。

这些能力现在分散在菜单栏、桌宠右键菜单、运行时配置、Keychain 和调试流程里。用户没有一个统一入口来管理，也很容易出现“界面保存了，但真实桌宠没有生效”的假设置问题。

第一版设置页要解决的是：让用户可以在一个地方调整桌宠基础行为，并让这些设置真实影响当前桌宠运行。

## Proposed Solution

设置页采用单页分组布局，从上到下展示四组内容。

### 1. 基础设置

提供“开关桌宠”。

- 作用等同于当前桌宠右键菜单里的“隐藏宠物”和菜单栏里的“开关宠物”。
- 只影响当前运行状态。
- 每次重新启动 Petsona 时，桌宠默认显示。
- 设置页、右键菜单、菜单栏三处状态要同步。

### 2. 行为设置

提供“行为变化频次”。

- 只控制无操作时自动换动作的间隔。
- 不影响用户点击动作。
- 不影响用户拖拽动作。
- 不影响说话气泡。
- 用户看到固定档位，底层保留按时间配置能力。

档位说明：

- 安静：约 5 分钟换一次动作。
- 正常：约 2 分钟换一次动作。
- 活跃：约 30 秒换一次动作。

### 3. 主动说话频次

提供“主动说话频次”。

- 只控制闲聊型主动说话。
- 不影响提醒事项。
- 不影响重要系统提示。
- 不影响错误提示。

档位说明：

- 活跃：约 15 分钟一次。
- 正常：约 45 分钟一次。
- 安静：约 2 小时一次。
- 关闭：不主动闲聊。

### 4. 自定义宠物描述

提供多行自由文本输入，并在输入框里给出示例提示。

- 最多 500 字。
- 自动保存。
- 显示字数提示。
- 超过 500 字时阻止继续输入或给出明确提示，不能静默丢内容。
- 这段描述作为用户定义的低优先级宠物人设 prompt。
- 它影响宠物回复风格和主动闲聊内容。
- 它的权重低于应用内置 system prompt；如果和内置规则、安全边界、产品边界冲突，以内置规则为准。

### 5. 调试设置：大模型 API 接口

放在设置页最后一组，视觉上弱化为调试/开发配置。

这是调试入口，不是面向最终用户正式开放的功能。

使用 OpenAI-compatible 三件套：

- Base URL
- API Key
- Model

API Key 规则：

- API Key 存 macOS Keychain。
- 设置页不明文回显 API Key。
- 已保存时只显示“已保存”和末四位。
- 支持清除 API Key。
- 支持替换 API Key。

调试能力：

- 提供“连接测试”按钮。
- 点击后使用当前 Base URL、API Key、Model 发一次最小请求。
- 显示成功或失败原因。

### 6. 恢复默认设置

提供“恢复默认设置”。

- 恢复普通设置。
- 不清除 API Key。
- API Key 只能在调试 API 区域单独清除或替换。

### 7. 保存反馈

- 保存失败时显示轻量错误提示，例如 toast 或顶部提示。
- 保存失败时不回滚 UI。
- 用户当前选择先保留在界面上，可再次操作。

## Technical Constraints

1. 设置页必须接真实能力，不做假 UI。
2. 开关桌宠要复用现有右键菜单和菜单栏的显示/隐藏逻辑。
3. 如果设置页缺少可调用的桌宠显示/隐藏桥接能力，必须补 Tauri 或 IPC command。
4. 桌宠显示状态不持久化；重启后默认显示。
5. 行为变化频次和主动说话频次是两个独立系统，不能混用同一个字段。
6. 行为变化频次只影响无操作时自动动作调度。
7. 主动说话频次应尽量复用现有 `high / mid / low / off` 配置。
8. 主动说话频次沿用当前约 `15 / 45 / 120` 分钟和关闭的语义。
9. API Key 必须走 Keychain，不允许明文写入普通配置文件。
10. Base URL 和 Model 可以持久化到本地配置。
11. 除 API 设置外，其它设置要即时生效。
12. API 设置保存后，下一次模型请求使用新配置，不要求重启。
13. 自定义宠物描述作为低优先级 prompt 注入，不能覆盖内置 system prompt、安全规则和产品边界。
14. 恢复默认设置不能清除 API Key。

## Non-goals

第一版不做：

1. 多宠物、多角色管理。
2. 云端账号同步设置。
3. 面向普通用户开放模型配置。
4. 复杂 prompt 编排器。
5. 行为规则引擎。
6. token 用量统计。
7. 费用统计。
8. API Key 云端托管。
9. 高级自定义滑杆。
10. 动画编辑器。
11. 团队、权限、多用户设置。

## Success Criteria

1. 用户能从设置页开关桌宠，效果与右键菜单、菜单栏一致。
2. 关闭桌宠后，本次运行内保持隐藏；重启后默认显示。
3. 用户能选择行为频次档位，并看到每个档位的时间说明。
4. 行为频次只影响无操作自动动作，不影响点击和拖拽。
5. 用户能选择主动说话频次，并看到每个档位的时间说明。
6. 主动说话频次只影响闲聊型主动说话。
7. 提醒事项和重要提示不受主动说话频次影响。
8. 用户能编辑 500 字以内宠物描述。
9. 宠物描述自动保存，并影响后续回复和主动闲聊风格。
10. 用户能填写 OpenAI-compatible API 配置。
11. 用户能测试 API 连接，并看到成功或失败原因。
12. API Key 不明文回显。
13. API Key 不明文落普通配置文件。
14. 恢复默认设置不会清除 API Key。
15. 保存失败有明确轻量提示。
16. 所有设置接真实系统能力，刷新或重开面板后状态正确展示。
